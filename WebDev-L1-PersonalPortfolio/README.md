### 📌 Project Overview
An ultra-sleek, responsive personal portfolio website engineered to showcase technical skills, real-world projects, work experience, and contact channels. Built with dark/light mode toggle, skill category filtering, and accessible semantic markup.

---

### ✨ Feature Checklist (As per Oasis Infobyte Specification)
- [x] **Profile / Hero Section**: Developer name ("Safin Ahmed"), role title ("Frontend Engineer & Creative Technologist"), animated availability indicator, social profiles (GitHub, LinkedIn, Email), and an illustrated developer silhouette avatar card.
- [x] **About Me Section**: Comprehensive 3-paragraph career narrative detailing web engineering ethos, design philosophy, and core focus areas (Pixel-Perfect, Zero-Jank, Accessible).
- [x] **Skills Section**: Visual interactive grid with category tabs (*All, Frontend Core, Frameworks & Tools, Design*), individual percentage meters, and descriptive summaries.
- [x] **Projects Section**: 4 detailed project showcase cards (AetherMind AI, TempSphere Pro, OmniCalc Studio, TaskFlow Pro) complete with tech tags, descriptions, live demo links, and GitHub repository links.
- [x] **Experience & Education Timeline**: Vertical timeline highlighting academic milestones and the Oasis Infobyte Web Development internship.
- [x] **Contact Section**: Interactive form with input validation (Name, Email, Subject, Message) and feedback toasts, along with 1-click email copy card and direct social links.
- [x] **Dark / Light Theme Toggle**: Persistent theme preference stored via `localStorage`.
- [x] **Smooth Scroll Navigation**: Seamless anchor scrolling with scrollspy active state tracking.
- [x] **Responsive Layout**: Fluid experience across mobile phones, tablets, laptops, and ultra-wide screens.
- [x] **Typography & Styling**: Google Fonts `Outfit`, `Plus Jakarta Sans`, and `JetBrains Mono`.
