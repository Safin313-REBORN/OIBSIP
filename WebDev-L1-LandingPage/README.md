## Level 1 · Task 1: Landing Page

**Project Name:** AetherMind AI — Autonomous Neural Canvas & Multi-Agent Swarms  
**Directory:** `OIBSIP/WebDev-L1-LandingPage/`  
**Track:** Web Development & Designing  
**Tech Stack:** HTML5, CSS3 (Modern Flexbox & Grid, CSS Custom Properties), Vanilla JavaScript  

---

### 📌 Project Overview
AetherMind AI is an ultra-modern, high-converting product landing page for a next-generation autonomous AI development platform. Built with a futuristic dark-mode aesthetic, luminous glassmorphism, responsive CSS layouts, and micro-interactions.

---

### ✨ Feature Checklist (As per Oasis Infobyte Specification)
- [x] **Sticky / Fixed Navigation Bar**: Fixed glass header with brand mark, 5 navigation links (Features, Platform Demo, Pricing, Wall of Love, FAQ), primary CTA button, and responsive mobile hamburger menu.
- [x] **Hero Section**: Powerful value proposition headline, subheadline, dual call-to-action buttons ("Launch Free Studio", "Watch 2-Min Demo"), live release badge, and social proof metrics.
- [x] **Interactive Hero Code Console**: Visual mock IDE demonstrating active multi-agent collaboration with simulated AST syntax and agent state indicators.
- [x] **Multiple Content Sections**:
  1. *Ecosystem Trust Bar*: Recognizable tech logos and metrics.
  2. *Core Features Grid*: 6 responsive cards with distinct color accents, SVG icons, and hover lift transitions.
  3. *Interactive Platform Demo*: Tabbed interface allowing users to preview Frontend, Backend, and Security capabilities with 1-click code copy.
  4. *Pricing Matrix*: 3 comprehensive subscription tiers (Starter, Pro, Enterprise) with an interactive **Monthly/Yearly billing discount toggle** (20% off).
  5. *Testimonials ("Wall of Love")*: Verified developer reviews with 5-star ratings, author credentials, and avatars.
  6. *FAQ Accordion*: Expandable/collapsible frequently asked questions.
  7. *Call To Action Banner*: Bottom conversion banner with gradient glass finish.
- [x] **Comprehensive Footer**: Brand overview, product links, resources, interactive newsletter subscription form with toast confirmation, and social links (GitHub, LinkedIn, Twitter/X).
- [x] **Consistent Colour Palette**: Curated dark palette using deep space hues (`#07090e`, `#0d111c`), electric violet (`#8b5cf6`), neon cyan (`#06b6d4`), and emerald accents.
- [x] **Fully Responsive**: Flawless experience across mobile, tablet, and desktop viewports using CSS Grid, Flexbox, and fluid typography (`clamp()`).
- [x] **Typography**: Google Fonts `Plus Jakarta Sans` and `Space Grotesk`.
